# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 4.0.x   | :white_check_mark: |
| < 4.0   | :x:                |

---

## Reporting a Vulnerability

The **noteX AI** team takes security vulnerabilities seriously.

If you discover a security vulnerability in noteX AI, please submit a report to:

📧 **security@notex.ai**

Please do **NOT** open a public GitHub issue for security vulnerabilities.

### What to include in your report:
1. Type of vulnerability (e.g., SQLi, XSS, CSRF, RCE, Auth Bypass).
2. Steps to reproduce the issue.
3. Impact assessment.
4. Suggested remediation (if available).

We will acknowledge receipt of your vulnerability report within 24 hours and send status updates until the issue is resolved.
