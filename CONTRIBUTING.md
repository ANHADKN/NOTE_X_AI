# Contributing to noteX AI

Thank you for your interest in contributing to **noteX AI**! We welcome contributions from developers, designers, AI researchers, and educators.

---

## 🛠️ How to Contribute

### 1. Reporting Bugs
- Search existing [GitHub Issues](https://github.com/notex-ai/noteX_AI/issues) to avoid duplicates.
- Include OS version, Python version, steps to reproduce, and terminal/browser log traces.

### 2. Suggesting Enhancements
- Open a feature request issue detailing the motivation, use case, and proposed implementation.

### 3. Pull Request Process
1. Fork the repository: `https://github.com/notex-ai/noteX_AI.git`.
2. Create your feature branch: `git checkout -b feature/amazing-feature`.
3. Ensure all tests pass:
   ```bash
   python scratch/test_all_modules.py
   ```
4. Commit your changes: `git commit -m 'Add awesome feature'`.
5. Push to your branch: `git push origin feature/amazing-feature`.
6. Submit a Pull Request targeting the `main` branch.

---

## 🎨 Code Style Guidelines

- **Python**: Follow PEP 8 guidelines. Use type hints where possible.
- **JavaScript**: Use modern ES6+ features with async/await.
- **CSS**: Follow standard Vanilla CSS variables defined in `index.css`.
- **Commit Messages**: Use semantic commit messages (e.g., `feat:`, `fix:`, `docs:`, `test:`).
