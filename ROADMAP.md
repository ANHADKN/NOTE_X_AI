# noteX AI Development Roadmap

This document outlines planned improvements and future features for **noteX AI**.

---

## 🎯 Version 4.x (Current Release — Stable Production)
- [x] ChatGPT / Gemini-style AI Tutor Homepage.
- [x] RAG Vector Search with ChromaDB and page citations.
- [x] Central AI Intent Router (`ai_router.py`).
- [x] Unified "My Library" asset repository.
- [x] AI Overview Dashboard.
- [x] Isolated Admin Panel with RBAC.
- [x] Multi-stage Docker containerization & Nginx reverse proxy.

---

## 🚀 Version 5.0 (Upcoming)
- [ ] **Multimodal Visual Reasoning**: OCR text extraction from textbook page snapshots and hand-drawn science diagrams.
- [ ] **Voice Interaction**: Native Text-to-Speech audio tutoring and speech recognition.
- [ ] **Real-time Streaming Websockets**: SSE (Server-Sent Events) streaming for AI tutor responses.
- [ ] **Redis Task Queue**: Background task processing for large multi-hundred page PDF indexing.
- [ ] **Multi-language Support**: Native English, Malayalam, Hindi, and regional language tutor prompts.
